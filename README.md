A colossal phoenix of fire and aurora rising over a night mountain lake — drawn entirely in code, standard library only.

## Run it

```
MAKEFUN_OUTPUT_DIR=out python3 -P -s main.py
```

This writes `out/entry.png` (768×768). The program is fully deterministic: run it twice and the bytes are identical.
